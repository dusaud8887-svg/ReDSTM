# ReDSTM 이미지 보관 도우미 (PC 크롬 확장)

아카라이브 이미지는 몇 시간짜리 서명 주소(`?expires=…&key=…`)로만 열리고, 로그인 없이 원문을 열면 성인 채널은
`451`, 서버에서 열면 봇 차단(`403`)입니다. 그래서 **이미 아카라이브에 로그인된 PC 크롬**이 이미지를 받아
ReDSTM(R2)에 영구 보관합니다. 폰에서는 보관된 이미지를 봅니다.

## 동작

1. ReDSTM에서 텍스트 장서(아카라이브) 글을 읽으면, 보관본이 없는 이미지의 글이 대기열에 올라갑니다
   (최근 읽은 글이 먼저).
2. 이 확장은 10분마다(또는 `지금 수집`으로) 대기열에서 글 5개씩 가져옵니다.
3. 이 크롬의 로그인으로 원문 글을 열어 지금 유효한 이미지 주소(`data-originalurl`, 원본)를 찾습니다.
4. 이미지를 가로 최대 1600px WebP(품질 80)로 줄여 업로드합니다. 움짤 GIF와 이미 작은 WebP/JPEG는 그대로 둡니다.
   아카라이브 접근 거부 대체 이미지(200×200 캐릭터)는 저장하지 않습니다. 영상은 받지 않습니다.
5. ReDSTM은 파일 내용 해시로 저장하므로 같은 이미지는 한 번만 저장됩니다.

## 설치 (PC 크롬)

1. `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드** → 이 폴더(`extension/redstm-arca-media`) 선택
3. 같은 크롬에서 ReDSTM(`https://redstm-edge.redstm-archive-private.workers.dev`)과 아카라이브에 로그인
4. 확장 아이콘 → **지금 수집**으로 한 번 확인

## 팝업 메시지

- `ReDSTM에 로그인되어 있지 않습니다` → ReDSTM 사이트를 한 번 열어 Cloudflare Access 로그인을 갱신
- 실패 사유 `아카라이브 로그인 필요 (451)` → 이 크롬에서 아카라이브에 로그인(성인 인증 포함)
- 같은 글은 5번까지 재시도하고, 그 뒤에는 다시 읽을 때 새로 대기열에 오릅니다.

## 권한

`arca.live`, `*.arca.live`, `*.namu.la`(이미지), ReDSTM 주소에만 접근합니다. 대기열에 오른 아카라이브 글
주소만 열며, 이미지 요청에만 `Referer: https://arca.live/`를 붙입니다.

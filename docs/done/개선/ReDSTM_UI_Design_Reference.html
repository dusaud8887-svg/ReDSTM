모바일 개편 명세의 화면 참조입니다.
게시판을 고르고, 200화를 읽고, 다음 화를 넘긴 뒤 목록으로 돌아가 보세요.

예시 작품·본문·건수이며 실서비스 데이터가 아닙니다. 디자인 시안의 화면 전환만 구현했습니다. 실제 브라우저 이력, 인증, 영구 저장, 원격 이미지·AA 렌더러, 접근성 적합성 검증은 별도 구현 대상입니다. 기본 프리뷰는 412 CSS px이며 S22+의 실측값이 아닙니다. 외부 폰트·네트워크 요청은 없습니다.

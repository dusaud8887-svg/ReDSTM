## 역사 요약 (v2.0 §2 원문 요지)

- 2026-07-11 "Moonlit Ledger"(전체 종이색 + violet + 초승달 + 명조 UI + 빈 표지)는 거절됐다. 원인은 **글꼴 누락 +
  모든 면이 따뜻함 + 장식이 정보보다 큼**이 겹친 faux-retro 인상.
- v1 Signal Archive(2026-07-12)는 흰 면·graphite·red 한 점으로 반동했다. 정확했지만 서재의 식별성·소장감이 약했고
  red가 오류·행동·위치를 겸했다.
- v2 Ribbon Library는 청록(행동)·주홍 가름끈(내 자리)으로 의미를 나누고, 서재와 본문의 표현 강도를 분리했다.
